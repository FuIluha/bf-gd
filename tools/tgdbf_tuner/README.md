# Пошаговый подбор TGDBF

Инструмент подбирает один интервал `delta=[0, upper]` отдельно на каждой
итерации. На фиксированной тренировочной выборке он сравнивает результат
**одного следующего шага** для порогов по сетке `--bin-width` на оси
`E - E_min`. Побеждает порог с минимальным FER на всех тренировочных словах;
при равном FER — с минимальным BER; при полном равенстве — наименьший порог.
Каждый порог включает нулевой бин, поэтому на активных словах всегда
происходит хотя бы один flip. Варианта без flip нет.

Энергия для каждого активного слова вычисляется один раз пробным вызовом
`step_state` с `delta=[0, 0]`; возвращённое состояние отбрасывается.
Возможные результаты порогов вычисляются из накопленных по бинам изменений
числа ошибочных битов и кадров, без повторного полного шага для каждого
порога. После выбора один общий порог применяется к тренировочной и
независимой проверочной выборкам. Декодер сохраняет своё состояние между
итерациями, включая возраст после последнего flip.

Каждый процесс держит собственные батчи обеих выборок. На каждой итерации
процессы сначала возвращают локальные результаты всех кандидатов, затем
главный процесс суммирует их и выбирает общий порог. Выборки состоят из
независимых реализаций AWGN для нулевого кодового слова. По умолчанию в каждой
10 000 слов, seed `42`, а `rho` состоит из нулей. Вероятностного flip в
TGDBF нет.

После каждой итерации в JSONL-лог записываются выбранный порог, параметры,
число кандидатов, счётчики бинов и BER/FER обеих выборок. Веб-интерфейс
показывает кривые BER/FER подбора и проверки; проверочная выборка не участвует
в выборе порога. Лог создаётся в `logs/` без перезаписи существующего файла.

Запуск из корня репозитория на сервере через интерактивное задание:

```bash
srun --job-name=tgdbf-tune --time=24:00:00 --cpus-per-task=128 \
  --chdir=/home/i.chevtaev/bf-gd --pty \
  /home/i.chevtaev/bf-gd/.venv/bin/python -u -m tools.tgdbf_tuner \
  --snr -0.5 --bin-width 0.05 --workers 128 \
  --rho 2,2,2,2,2,1,1 --L 7 --iterations 300 \
  --host 0.0.0.0 --port 8051
```

После запуска инструмент выведет имя вычислительного узла. **На локальном
компьютере** откройте SSH-туннель к нему:

```bash
ssh -N -L 8051:ИМЯ_УЗЛА:8051 entropy
```

Затем откройте `http://127.0.0.1:8051/` на локальном компьютере.
Параметры `--train-frames`, `--eval-frames`, `--seed`, `--alpha`, `--rho`,
`--L`, `--iterations`, `--code` и `--output` можно задать перед запуском.
Нулевая итерация и причина остановки тоже записываются в лог.
