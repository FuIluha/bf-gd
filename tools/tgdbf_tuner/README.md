# Пошаговый подбор TGDBF

Инструмент подбирает один интервал `delta=[0, upper]` отдельно на каждой
итерации. В обучающей выборке собираются частоты по фиксированным бинам
`E - E_min`. Начиная с нулевого бина, интервал расширяется, пока в каждом
следующем бине отношение числа ошибочных битов к числу правильных битов
не меньше `N`. Это потенциально правильные и неправильные flip; выбор
порога выполняется до реального шага. Если неправильных битов в бине нет,
но ошибочные есть, отношение считается бесконечным. Пустой бин останавливает
расширение интервала. Если первый бин не подходит, подбор останавливается.

Каждый процесс держит свой батч слов и состояния декодера. На каждой
итерации все процессы сначала возвращают локальные счётчики, затем один
общий порог рассылается обратно всем процессам. Обучающая и проверочная
выборки состоят из независимых реализаций AWGN для нулевого кодового слова.
Графики BER и FER в веб-интерфейсе рассчитываются по проверочной выборке.
`rho` по умолчанию состоит из нулей; вероятностного flip в TGDBF нет.

Запуск из корня репозитория, например на сервере через интерактивное задание:

```bash
srun --job-name=tgdbf-tune --time=24:00:00 --cpus-per-task=128 \
  --chdir=/home/i.chevtaev/bf-gd --pty \
  /home/i.chevtaev/bf-gd/.venv/bin/python -u -m tools.tgdbf_tuner \
  --snr -0.25 --ratio 2 --bin-width 0.25 --workers 128 \
  --host 0.0.0.0 --port 8051
```

После запуска инструмент выведет имя вычислительного узла. **На локальном
компьютере** откройте SSH-туннель к нему:

```bash
ssh -N -L 8051:ИМЯ_УЗЛА:8051 entropy
```

Затем откройте `http://127.0.0.1:8051/` на локальном компьютере.
JSONL-лог создаётся в `logs/` и не перезаписывает существующий файл.
Параметры `--train-frames`, `--eval-frames`, `--seed`, `--alpha`, `--rho`,
`--L`, `--iterations`, `--code` и `--output` можно задать перед запуском.
Нулевая итерация и остановка тоже записываются в лог.
