# LDPC Decision Energy Explorer

Локальное веб-приложение для пошагового исследования решений FTGDBF и
PMGDBF на одном фиксированном наборе кодовых слов и реализаций AWGN.

## Возможности

- слайдеры и ручной ввод всех параметров декодера;
- неизменяемые снимки состояния и линейные шаги назад/вперёд;
- классификация по фактическому действию: верный/ошибочный flip и no-flip;
- энергия `E` и запас до порога `E - E_threshold`;
- плотность вероятности или количество битов, линейная или логарифмическая
  ось Y;
- адаптивные общие бины по правилу Freedman–Diaconis с безопасными fallback;
- текущие и предварительные BER/FER;
- сохранение/загрузка всей сессии, экспорт CSV/JSON/PNG и наложение истории
  из второй сессии;
- воспроизводимая случайная маска PMGDBF, не зависящая от числа потоков.

## Запуск

Из корня репозитория:

```bash
source .venv/bin/activate
pip install -r visualisation/error_by_energy_visualisation/requirements.txt
python -m visualisation.error_by_energy_visualisation
```

По умолчанию заранее создаются 1000 всенулевых кодовых слов при SNR = 1 dB,
используется seed 1 и один рабочий поток. При BPSK переданным символом для
каждого бита является `+1`. Параметры набора задаются только при старте,
поэтому все шаги и оба алгоритма сравниваются на одних данных:

```bash
python -m visualisation.error_by_energy_visualisation \
  --frames 1000 \
  --snr 1.0 \
  --seed 1 \
  --workers 8 \
  --port 8050
```

Другой JSON кода можно явно выбрать через `--code`. Если он содержит поле
`generator`, приложение будет генерировать случайные информационные слова;
для этого должна быть собрана библиотека `lbc_encoder_impl.so`.

После запуска открыть `http://127.0.0.1:8050`.

Для сервера приложение можно слушать на всех интерфейсах:

```bash
python -m visualisation.error_by_energy_visualisation \
  --host 0.0.0.0 \
  --port 8050 \
  --workers 32 \
  --frames 1000
```

Порт должен быть разрешён правилами сервера. Более безопасный вариант —
оставить `--host 127.0.0.1` и открыть SSH-туннель с локального компьютера:

```bash
ssh -L 8050:127.0.0.1:8050 entropy
```

Число `--workers` управляет потоками кодирования и одного шага декодера.
Веб-сервер также обслуживает HTTP-запросы в потоковом режиме. Большие
значения следует подбирать по числу доступных CPU и памяти узла.

## Семантика шага

На снимке `k` график является предпросмотром решения `k → k+1` с текущими
значениями контролов. Кнопка «Вперёд» фиксирует новый снимок. «Назад» только
перемещает указатель, не меняя уже рассчитанные состояния. Новый шаг из
прошлого удаляет прежние последующие снимки и продолжает единственную
линейную историю.

Для PMGDBF случайные числа детерминированы seed и номером итерации. Поэтому
изменение `alpha`, `delta`, `p`, `rho` или `L` на одном снимке не подменяет
эффект параметров новой случайной реализацией.

Сравнение принимается только для истории на том же самом фиксированном
батче (проверяется SHA-256 входных значений и переданных символов). Это не
даёт случайно наложить BER/FER от другого SNR или seed.

## Проверка

Короткие unit-тесты не запускают статистический эксперимент:

```bash
python -m unittest discover \
  -s visualisation/error_by_energy_visualisation/tests \
  -v
```

Сессия сохраняется как сжатый NPZ и включает входной набор и все снимки.
JSON и CSV содержат компактный текущий срез, а PNG выгружается кнопкой
камеры в панели Plotly.
